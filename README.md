# RetKit × MoEngage

RetKit — userscript для работы с HTML-письмами внутри MoEngage.

MoEngage остаётся источником данных и сам отправляет кампании. RetKit просто даёт нормальное рабочее окно поверх его редактора: код, preview, локали, поиск/замена и несколько полезных действий, которые в родном интерфейсе делать долго или неудобно.

## Что умеет

### HTML workspace

- полноэкранный HTML-редактор;
- форматирование кода, номера строк, Wrap и folding;
- live preview рядом с кодом;
- клик по тексту/картинке/ссылке в preview переводит к нужному месту в HTML;
- `Copy HTML`;
- быстрый HTML validator;
- изменения синхронизируются обратно в нативный редактор MoEngage.

RetKit старается не считать синхронизацию успешной вслепую: после записи он проверяет, не откатил ли MoEngage HTML обратно.

### Локали

Верхняя строка локалей работает с реальными локалями текущей кампании.

- переключение локали прямо из RetKit;
- `+ Locale` читает нативный список MoEngage и добавляет только доступные локали;
- не-default локаль можно удалить через нативный MoEngage flow;
- `Backup ZIP` сохраняет HTML локалей перед рискованной массовой правкой;
- `RTL Fix` помогает с арабской/RTL-версией и умеет откатить последнюю правку.

RetKit не хранит отдельную «копию мира»: если локаль не существует в MoEngage, он не должен изображать, что она существует.

### ↶ Original — страховка на первую версию

Перед самой первой правкой письма RetKit тихо запоминает, каким оно было (отдельно для каждой локали). В тулбаре появляется **↶ Original**: можно посмотреть, когда сохранено, скопировать исходный HTML или вернуть его одной кнопкой. Возврат — обычная правка: `Cmd/Ctrl+Z` в редакторе отменяет и его.

Хранится только в этом браузере (IndexedDB, не в localStorage MoEngage). Неиспользуемые оригиналы удаляются сами через 14 дней, общий объём ограничен 40 МБ; ненужный можно удалить кнопкой **Forget**.

### Find / Replace

Обычный `Cmd+F` / `Ctrl+F` работает в текущем HTML.

Для массовой правки есть **Across locales**:

1. RetKit проходит по созданным локалям и считает точные совпадения.
2. Можно оставить только нужные языки.
3. Замена выполняется по локалям по очереди.
4. После каждой записи RetKit проверяет, что MoEngage сохранил результат.
5. Для последней массовой замены доступен локальный undo.

Это удобно, например, чтобы одним проходом заменить URL, `src`, кусок текста или общий фрагмент HTML во всех переводах.

### Subject и тестовые письма

Subject в RetKit связан с нативным Subject MoEngage.

`Send test` сейчас работает как безопасный handoff: RetKit временно скрывается, прокручивает страницу к родному **Test Campaign** MoEngage и оставляет сверху кнопку **Return to RetKit**. Сам тест отправляется вручную в MoEngage. Так меньше магии и меньше риска сломаться после очередного обновления их UI.

### AI — опционально

В RetKit есть локальная интеграция с установленными **Codex** и **Claude Code**.

Модель работает твоей подпиской (Claude Code или Codex на этом компьютере) и видит:

- **код** текущего письма, subject, выделенный фрагмент, ошибки валидатора;
- **все локали** кампании: список, HTML любой локали, переключение;
- **письмо глазами** — `get_preview_screenshot` рендерит текущее превью в PNG через твой же Chrome (desktop или mobile) и отдаёт картинку модели. Скрипты из письма при этом не выполняются.

Изменения HTML/subject модель только **предлагает**: diff показывается в RetKit и применяется после твоего подтверждения.

Сам editor от AI не зависит. Если локальный bridge не запущен, обычная работа RetKit продолжает работать.

Чтобы запустить bridge:

```bash
cd bridge
npm install
npm start
```

**Автозапуск bridge не используется:** на управляемых рабочих компьютерах средства защиты считают новые элементы автозапуска (LaunchAgent) признаком закрепления вредоносной программы. Если ставили раньше — удалите: `npm run bridge:uninstall`.

Bridge слушает только `127.0.0.1:43118`. Для скриншотов нужен установленный Google Chrome (или Chromium/Edge/Brave); если он стоит не в стандартном месте — `RETKIT_CHROME=/путь/к/chrome npm start`.

## Установка

Займёт пару минут. Нужен Chrome (или любой Chromium-браузер) и Tampermonkey.

1. Поставь расширение **Tampermonkey** из Chrome Web Store.
2. Открой `chrome://extensions` → Tampermonkey → **Подробнее** и включи **Allow User Scripts** (в новых версиях Chrome без этого userscript не запускается). Если такого переключателя нет — включи **Режим разработчика** в правом верхнем углу той же страницы.
3. Открой в браузере ссылку:

   ```text
   https://raw.githubusercontent.com/Brokenbass90/retkit-moeng/main/dist/retkit-moengage.user.js
   ```

   Tampermonkey сам покажет страницу установки → **Install** (или **Update**, если RetKit уже стоит).
4. Перезагрузи вкладку MoEngage и открой HTML-редактор письма — справа внизу появится синяя кнопка **RK**.

**Обновления** приходят сами: Tampermonkey периодически проверяет `main`. Проверить вручную: иконка Tampermonkey → Utilities → **Check for userscript updates**.

**Тестовая версия из ветки:** та же ссылка, только вместо `main` — имя ветки, например `.../retkit-moeng/polish/v0.7/dist/retkit-moengage.user.js`.

**Что RetKit делает с данными:** HTML писем никуда не отправляется. Резервные «оригиналы» и настройки хранятся только в твоём браузере. AI-панель работает только если ты сам запустил локальный bridge, и тогда общается только с твоим собственным Claude Code / Codex.

## Если что-то сломалось

RetKit работает поверх внутреннего DOM MoEngage, поэтому крупное обновление их интерфейса может сломать конкретный bridge: локали, Subject, Test Campaign и т.п.

В таком случае полезнее всего прислать:

- что именно нажималось;
- скрин нативного блока MoEngage;
- экспорт из `Logs`, если RetKit его предлагает;
- ошибку из Console, если она есть.

Содержимое HTML в diagnostics по умолчанию не добавляется.

## Разработка

Нужен Node.js 20+.

```bash
npm run check      # сборка + все тесты + тесты AI bridge
npm test           # только тесты (перед этим npm run build)
npm test -- locale # только тест-файлы, в имени которых есть "locale"
```

### Структура

```text
src/
  core/retkit-moengage-core.user.js   редактор, preview, синхронизация с Froala/CodeMirror, find/replace, validator
  moengage/native-bridge.user.js      мост к родному UI MoEngage: локали, Subject, RTL, Test Campaign, Backup ZIP
  ai/                                  панель AI и клиент локального bridge
  diagnostics/incident-recorder.js     журнал инцидентов (Logs)
bridge/                                локальный AI bridge (Node, 127.0.0.1:43118)
scripts/                               build, test-runner, set-version, package
tests/                                 регрессионные тесты + fixtures/
dist/retkit-moengage.user.js           собранный userscript — единственный файл для Tampermonkey
shared/click-to-source.js              общий матчер «клик в превью → код» для Retention Future (генерируется)
```

`dist/` собирается из `src/` командой `npm run build`; руками его не правим.

### Релиз

```bash
npm run version:set -- 0.7.1   # меняет версию во всех местах сразу
npm run check
git commit -am "release: v0.7.1" && git push
```

После push в `main` Tampermonkey подтянет новую версию по `@updateURL`. `test-version-consistency` не даст собрать релиз, если версия где-то разъехалась.
