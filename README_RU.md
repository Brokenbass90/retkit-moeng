# RetKit × MoEngage

> Текущая упакованная версия: **v0.5.9**.


RetKit это браузерная надстройка для работы с HTML-письмами прямо внутри MoEngage.

MoEngage остаётся источником письма и отправляет кампанию как обычно. RetKit просто делает разработку удобнее: открывает нормальное полноэкранное окно с кодом, большим предпросмотром, переходом из превью прямо к нужному месту HTML, поиском/заменой, сворачиванием блоков, историей состояний и валидатором.

![Рабочее окно RetKit](docs/screenshots/retkit-workspace.png)

## Что есть в v0.4.0

- Полноэкранный редактор HTML.
- Автоматическое форматирование кода для удобного чтения.
- Номера строк.
- `Wrap` для переноса длинных строк.
- Разделитель между кодом и превью можно тянуть мышкой.
- Иконки desktop/mobile находятся в самом окне Preview.
- Клик по элементу справа переносит к его коду слева.
- Нормальная работа с текстом вида `обычный текст <b>жирный</b> обычный текст`.
- Учитываются повторяющиеся картинки и одинаковые ссылки.
- `Cmd+F` / `Ctrl+F`: поиск и замена.
- Replace и Replace All.
- Стрелки возле строк для сворачивания больших HTML-блоков.
- Изменения автоматически применяются обратно в MoEngage.
- `Apply now` для ручной повторной попытки.
- До 10 локальных сохранённых состояний письма с откатом.
- HTML-валидатор с переходом прямо на проблемную строку.
- Автообновления через Tampermonkey после публикации репозитория.

## Установка в Arc с самого начала

Arc умеет ставить расширения Chrome, поэтому отдельной версии RetKit для Arc нет.

1. Открой Arc.
2. Открой **Интернет-магазин Chrome**.
3. В поиске напиши **Tampermonkey**.
4. Открой официальное расширение Tampermonkey.
5. Нажми **Установить / Добавить в Chrome**.
6. Подтверди установку расширения.
7. Открой страницу расширений Arc и проверь, что Tampermonkey включён.
8. Если в настройках Tampermonkey/Arc есть переключатель **Разрешить пользовательские скрипты**, включи его.
9. Нажми на Tampermonkey → открой панель Tampermonkey.
10. Нажми кнопку `+` / **Создать новый скрипт**.
11. Удали стандартный текст из редактора.
12. Открой файл `dist/retkit-moengage.user.js` из этого репозитория и вставь его содержимое.
13. Нажми `Cmd+S`.
14. Вернись в MoEngage и перезагрузи страницу `Cmd+R`.

После публикации репозитория можно будет просто открыть raw-файл:

`https://raw.githubusercontent.com/Brokenbass90/retkit-moeng/main/dist/retkit-moengage.user.js`

Tampermonkey сам покажет окно установки.

## Установка в Google Chrome

1. Открой Chrome.
2. Открой **Интернет-магазин Chrome**.
3. Найди **Tampermonkey**.
4. Установи официальное расширение.
5. Открой `chrome://extensions`.
6. Проверь, что Tampermonkey включён.
7. Нажми **Сведения** у Tampermonkey.
8. Если есть пункт **Разрешить пользовательские скрипты**, включи его.
9. Открой Tampermonkey → **Создать новый скрипт**.
10. Вставь содержимое `dist/retkit-moengage.user.js`.
11. Сохрани.
12. Перезагрузи MoEngage.

## Как открыть RetKit в MoEngage

1. Открой нужное письмо/Email Campaign в MoEngage.
2. Открой HTML/Code View редактор письма.
3. Дождись, пока справа появится родной Preview MoEngage.
4. В правом нижнем углу появится синяя кнопка **RK**.
5. Нажми на неё.

![Кнопка RK](docs/screenshots/moengage-rk-button.png)

Если кнопки нет, смотри раздел **Если что-то не работает** ниже.

## Что находится в рабочем окне

Слева код. Справа письмо.

Границу между ними можно тянуть мышкой влево и вправо. RetKit не должен запоминать старую позицию элементов для клика: при каждом новом клике он заново смотрит текущий DOM превью и текущий HTML.

### Wrap

Кнопка `Wrap` включает и выключает перенос длинных строк. Состояние сохраняется в браузере.

### Desktop и Mobile

В правом верхнем углу Preview есть две маленькие иконки: монитор и телефон.

Они меняют только ширину локального предпросмотра RetKit. Это не таргетинг кампании и не определение устройства пользователя.

## Клик по письму → нужный код

Нажми на текст, кнопку, ссылку или картинку справа.

RetKit старается выделить слева именно то, что ты нажал:

- картинка → её `src`;
- обычный текст → конкретный текстовый кусок;
- жирный текст → текст внутри нужного `<b>`;
- одинаковые картинки/ссылки → конкретное совпадение, а не обязательно первое в письме.

Например:

```html
<p>
  Go to <b>PROMO</b>, pick the offer → Click <b>Deposit</b>
</p>
```

Нажал на `PROMO` → выделился только `PROMO`.

Нажал на `pick the offer` → выделился именно этот обычный текст, а не весь `<p>` вместе со всеми `<b>`.

## Поиск и замена

Mac:

- `Cmd+F` → поиск + поле **Replace with**.
- `Cmd+Option+F` → то же самое.

Windows:

- `Ctrl+F` → поиск + замена.
- `Ctrl+H` → поиск + замена.

Есть переход к предыдущему/следующему совпадению, Replace и Replace All.

## Сворачивание HTML

Слева возле номера строки появляются маленькие стрелки у больших тегов.

Можно свернуть, например, большой `<table>...</table>` или `<div>...</div>`, чтобы он не занимал полэкрана. Сам HTML при этом не меняется.

## Как изменения попадают обратно в MoEngage

При обычном редактировании RetKit сразу обновляет своё Preview и автоматически пытается применить новый HTML в MoEngage.

Под капотом он использует уже загруженные MoEngage редакторы:

1. Передаёт код в родной CodeMirror.
2. Имитирует нормальное изменение редактора.
3. Переключает Froala Code View туда и обратно.
4. Проверяет, что MoEngage не вернул старую версию HTML.

Если автоматическая попытка не прошла, нажми **Apply now**. Статус сверху напишет, принял ли MoEngage изменения.

![Родной редактор MoEngage](docs/screenshots/moengage-native-editor.png)

## Сохранённые состояния и откат

Это локальная страховка от случайно удалённого куска письма.

- Нажми **Save** → текущее состояние сохранится.
- Нажми **History** → увидишь до 10 последних состояний этого письма.
- Нажми на нужное состояние → RetKit его восстановит.
- Перед восстановлением RetKit автоматически сохранит текущее состояние как **Before restore**.

То есть если откатился не туда, можно откатить даже сам откат.

Всё лежит только в `localStorage` текущего браузера. На сервер RetKit историю не отправляет.

## HTML Validator

Верхняя панель показывает:

- `✓ HTML` если явных структурных проблем не найдено;
- `⚠ N issues` если есть предупреждения/ошибки.

Нажми на статус → откроется список. Нажми на конкретную проблему → RetKit переведёт редактор на нужную строку.

Сейчас проверяется:

- лишний закрывающий тег;
- незакрытый обычный тег;
- `<a>` внутри другого `<a>`;
- пустой `href` или `href="#"`;
- `<img>` без `src`;
- `<img>` без `alt`.

Email-специфика учитывается:

- `img`, `br`, `meta` и другие void-теги не обязаны закрываться;
- HTML comments и Outlook conditional comments не участвуют в стеке тегов;
- содержимое `style`, `script`, `pre`, `textarea` не разбирается как обычный HTML.

Это быстрый помощник, а не полноценный W3C-валидатор.

## Автообновление

В скрипте прописаны:

```text
@updateURL   https://raw.githubusercontent.com/Brokenbass90/retkit-moeng/main/dist/retkit-moengage.user.js
@downloadURL https://raw.githubusercontent.com/Brokenbass90/retkit-moeng/main/dist/retkit-moengage.user.js
```

Когда репозиторий `Brokenbass90/retkit-moeng` будет опубликован, Tampermonkey сможет сам проверять этот файл и накатывать новую версию.

Номер текущей версии видно прямо в верхней панели RetKit: `v0.4.0`.

## Если что-то не работает

### Не появилась кнопка RK

Проверь по порядку:

1. Адрес начинается с `https://dashboard-02.moengage.com/`.
2. Tampermonkey включён.
3. Сам скрипт RetKit включён в Tampermonkey.
4. В расширениях браузера разрешены пользовательские скрипты.
5. В MoEngage открыт именно email HTML editor.
6. Родной редактор успел загрузиться.
7. После установки/обновления RetKit страницу MoEngage надо перезагрузить.

### Пишет, что Preview не готов

Сначала дождись родного Preview MoEngage, потом ещё раз нажми RK.

### В RetKit код поменялся, а MoEngage не принял

Нажми **Apply now** и посмотри сообщение в верхней панели. Интеграция зависит от внутреннего редактора MoEngage, поэтому RetKit специально проверяет, не откатил ли MoEngage HTML обратно.

### Клик ведёт не на тот одинаковый блок

v0.4 учитывает порядковый номер одинаковых `src` и `href`, а mapping пересчитывается при каждом клике. Если останется конкретный кейс, для бага полезны два фрагмента: скрин блока в Preview и соответствующий кусок HTML.

## Приватность

RetKit:

- работает локально в браузере;
- не отправляет содержимое письма на свой сервер;
- не собирает логины/пароли;
- не обходит роли и права MoEngage;
- хранит snapshots только локально.

Как и с любым userscript, перед установкой в рабочий браузер код можно и нужно просмотреть.
